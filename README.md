# Aether

Aether is an on-device iOS app manager for importing, signing, installing, and managing apps. It also includes device tools for pairing, tunnelling, installed-app management, and location spoofing.

It started as a fork of [Feather](https://github.com/claration/feather) by Samara, then took a pretty different path with substantial work around device tools, tunnelling, and location spoofing.

## Download

Get the latest IPA from the [releases page](https://github.com/a-artho/Aether/releases).
