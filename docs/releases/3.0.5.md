# Aether 3.0.5

- For an In-App VPN self-update, wait four seconds after the Install command is flushed, then stop the VPN and confirm disconnection before ending background work and suspending for iOS to replace Aether.
- Do not wait for an installation-service reply before beginning the self-update handoff; tolerate iOS interrupting Aether's background task during the grace period.
- Keep the special handoff limited to self-installs through In-App mode; normal installs and LocalDevVPN behavior remain unchanged.
- Keep same-build reinstall recovery and foreground verification for inconclusive outcomes.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
