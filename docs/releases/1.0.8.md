Aether 1.0.8 improves signing, installation progress, and Library behavior.

- Reports real signing and hashing progress, plus continuous payload transfer progress in iDevice and Server modes.
- Prevents unfinished signing jobs from appearing in Signed or briefly showing Queued.
- Shows a loading indicator during bulk Library deletion and moves file cleanup off the main thread.
- Adds small-size fallback artwork for the Aether Dark icon.
- Retains the optional Match Certificate Identity toggle for signing Aether itself, off by default.

This release follows the 1.0.6 settings and server behavior; it does not include the CA server setup introduced in the original 1.0.7 release.

The IPA is unsigned, without provisioning profiles or ad-hoc executable signatures. Sign it with your own certificate before installing. iOS still controls background execution and may request confirmation during long operations.
