# Aether 3.0.6

- Fix the In-App VPN self-update handoff: keep the tunnel and background task alive for four seconds after the install command is flushed, then disconnect the tunnel before suspending Aether.
- Handle iOS interrupting the continued background task during that grace period without abandoning the scheduled handoff.
- Keep this behavior limited to self-updates through In-App VPN; normal installs and LocalDevVPN remain unchanged.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
