# Aether 3.0.2

- Improve automatic tunnel connection and recovery across cold launches, foreground transitions, and cellular changes.
- Fix brief incorrect tunnel and setup placeholders while a connection is starting.
- Improve self-update installation handoff and recovery when iOS suspends Aether.
- Refine Library installation cleanup and strengthen lifecycle regression checks.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
