# Aether 3.0.9

- Fix automatic connection recovery around foregrounding, idle disconnects, tunnel state changes, and Cellular Assist callbacks.
- Keep completed repo downloads marked as in the Library and add a Download Again action.
- Improve update version labels and let you ignore current releases or all future updates.
- Reduce repo-opening stalls and Library file checks on the main thread.
- Fix interrupted search cleanup, stale focus updates, and missing search animation anchors across navigation layouts.
- Keep navigation title styling responsive to Appearance changes without repeating unchanged window-wide updates.
- Present uninstall confirmation from the selected app row.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
