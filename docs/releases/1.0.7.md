Aether 1.0.7 adds an optional Match Certificate Identity toggle when signing Aether itself.

- The toggle is off by default. When enabled, it selects the bundle identifier from the selected certificate’s explicit provisioning profile.
- Updates Aether’s extension and background-task identifiers consistently, including stale original identifiers on an externally renamed copy.
- Keeps existing URL callback schemes, file-type declarations, and VPN extension signing behavior.
- Rejects expired or wildcard profiles and conflicting signing options, and revalidates the selected profile when the queued signing job runs.

All other app behavior follows 1.0.6. Changing Aether’s identity can create a separate installation with new data and notification permissions.

The IPA is unsigned and contains no provisioning profiles or ad-hoc executable signatures. Sign it with your own certificate before installing.
