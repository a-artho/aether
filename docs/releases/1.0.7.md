Aether 1.0.7 adds on-device certificate setup for Fully Local server installation and reorganizes installation settings.

- Choose Server or iDevice from Settings → Installation; both controls share the Device tab’s switching guards.
- Find Tunneling and Pairing under iDevice, and server configuration under Server.
- Fully Local generates a device-local CA and HTTPS certificate, opens the CA profile download, checks system trust, and renews the HTTPS certificate without replacing a valid CA. Installing the profile and enabling full trust remain manual iOS steps.
- Reset the generated CA and HTTPS credentials under Settings → Reset. Remove the installed iOS profile manually in Settings.
- Semi Local retains its existing installation flow and localhost option.
- Aether’s signing sheet includes an optional certificate identity matching toggle for signing Aether itself. It is off by default.

The IPA is unsigned and contains no provisioning profiles or ad-hoc executable signatures. Sign it with your own certificate before installing.
