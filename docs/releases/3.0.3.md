# Aether 3.0.3

- Add an optional Liquid Glass style for action buttons while keeping the existing style as the default.
- Extend the ambient background setting with an adjustable top-glow reach.
- Refine Appearance settings for source list insets and description sizing.
- Add regression coverage to keep Action Button Style discoverable in Settings search.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
