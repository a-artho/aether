# Aether 2.0.1

- Added Default, Compact, and Balanced row text options and a cold-launch tab preference.
- Fixed the brief tunnel-unavailable message before automatic launch connection.
- Improved installed-app icon presentation, thumbnail memory use, and first-screen prefetching.
- Synced Library update checks with repository refreshes and added independent repository-row progress.
- Made installed-app Info a native compact sheet with scrolling and expansion to full height.

The IPA and included VPN extension are fully unsigned, without ad hoc signatures or embedded provisioning profiles. Sign with your certificate and profile before installing.
