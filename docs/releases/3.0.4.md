# Aether 3.0.4

- Improve in-app tunnel recovery when returning from background or retrying after a stalled RSD connection.
- Bound native RSD connection and service check-in waits so timed-out attempts release resources and can retry.
- Hand off self-install backgrounding after the Install command is sent, without waiting for a progress callback.
- Refine the ambient top glow scaling and add the system action-button surface option.
- Extend tunnel lifecycle and self-update regression coverage.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
