Aether 1.0.9 improves concurrency correctness and updates the app for current iOS APIs.

- Fixes UI and background-worker ownership across signing, installation, imports, storage, and tunnel callbacks.
- Prevents delayed packet callbacks from affecting a stopped or restarted tunnel.
- Makes app metadata, log values, and text/icon caches safe to use across workers.
- Updates deprecated SwiftUI, MapKit, and icon-rendering APIs while preserving existing flows and styling.
- Resolves all 240 application source warning locations from the previous audit.
- Removes obsolete saved-data migrations and unused platform compatibility code for the iOS 26+ app.

Validation includes all 83 regression tests, focused signing/tunnel/progress checks, a fresh iPhone build, and unsigned IPA verification.

The IPA is unsigned, without provisioning profiles or ad-hoc executable signatures. Sign it with your own certificate before installing.
