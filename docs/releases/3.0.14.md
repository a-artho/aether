# Aether 3.0.14

- Match local network tunnel packet sizing to pymobiledevice3's dynamic probing and recovery behavior.
- Preserve individual packet boundaries and retire the fixed-MSS and packet-batching options.
- Improve tunnel recovery when packet delivery limits change during a transfer.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
