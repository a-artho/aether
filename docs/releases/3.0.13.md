# Aether 3.0.13

- Reduce avoidable copies and temporary memory retention during AFC uploads and tunnel transport.
- Make native logging follow the Debug Logs setting, including when it changes during an upload.
- Add opt-in transport experiments for packet batching, MTU, and send-window tuning; defaults remain unchanged.

The release IPA is fully unsigned, including the in-app VPN extension. It contains no ad-hoc signatures or embedded provisioning profiles and must be signed before installation.
