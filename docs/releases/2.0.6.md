# Aether 2.0.6

- Improve Imports row handoffs, status crossfades, cancellation, and swipe deletion.
- Keep system-default row spacing and remove the inset option.
- Add Default, Medium, and Large row icon sizes (50, 54, and 58), with matching loading skeletons.
- Add Standalone, Black, System, and native Glass overview icon styles, optionally applied to individual repo artwork.
- Add App Store, original Globe, and Books choices for All Repos.
- Fade All Apps subtitle changes and stabilize its loading/count accessory.
- Add swipe-to-ignore updates per installed app, persistent exclusions, and Reset Ignored Updates.
- Improve continuous progress, status changes, and Reduce Motion support in Imports.
- Prevent transient rows during import/signing completion and cancellation, including delayed database updates.
- Clean failed signed-record insertions without discarding unrelated edits.
- Improve IPA file-picker type handling and prevent duplicate completion callbacks.
- Use a native prominent Liquid Glass signing button and move Post Signing to the top of Signing Options.
- Add Default repository ordering while retaining Latest as the initial choice.
- Keep All Repos with a muted App Store logo.
- Simplify repository display names and remove unused download-icon styling.
- Keep network configuration expandable inside Aether Tunnel, with aligned rows and no redundant heading.
- Improve search focus handling, icon selection, and copy feedback.
- Reduce redundant spoofing connection checks and shorten developer-service discovery with fallback.
- Improve spoofing cancellation, route timing, and protection against stale map results.

The IPA is unsigned, includes the in-app VPN extension, and requires signing before installation.
